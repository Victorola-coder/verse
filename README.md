# Verse

A minimalist, cinematic quote-sharing experience.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- Native CSS transitions only

## Structure

```
app/          # Routes, layout, global styles
components/   # UI components
lib/          # Shared logic
types/        # TypeScript types
utils/        # Helpers
```

## Development

```bash
bun install
bun dev
```
